# Simple plugin for Kodi mediacenter

API client (GUI) for [kodi-api-server](https://github.com/sakaljurgis/kodi-api-server). Draft version, but fully functional.

Based on Roman V. M. example plugin: [plugin.video.example](https://github.com/romanvm/plugin.video.example)

Do **not** try to install a .zip generated by GitHub.

Compatible with Kodi 19.0 ("Matrix") and above that uses Python 3.

Settings: the server URL (e.g. `https://media.example.com`; a value ending with `/api`, as older
versions had it, works too) and an optional auth key, sent as the `Authorization` header.

Watched state and resume points live on the server, shared with other apps (e.g. SKLK TV): listings
come with them, and a background service (`service.py`) reports playback (every 30 s, on pause, stop
and end). On its first start the service also sends Kodi's existing watched history of this add-on to
the server. Mark watched/unwatched with the add-on's own context menu entries ("Mark watched",
"Mark all watched", ...); Kodi's built-in "Mark as watched" only changes Kodi's local database.
